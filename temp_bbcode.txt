[size=24pt][b]Назначение[/b][/size]

[b]Модуль автоматически заменяет подключения к API Яндекс карт на заданный URL, обеспечивая единый и корректный способ подключения библиотеки [/b][code]ymaps[/code][b]. Это особенно полезно в ситуациях, когда несколько модулей (например, [/b][code]awz.ydelivery[/code][b], [/b][code]awz.belpost[/code][b], [/b][code]awz.europost[/code][b]) подключают карты с разными ключами и версиями, что приводит к конфликтам и ошибкам.[/b]

[size=24pt][b]Основные возможности[/b][/size]

[list]
[*][b]Автоматическая замена скриптов[/b]: Модуль перехватывает HTML-контент страницы и заменяет все подключения к [/b][code]api-maps.yandex.ru[/code][b] на единый URL, указанный в настройках.
[*][b]Гибкая настройка[/b]: Возможность включать/отключать модуль на отдельных сайтах (для мультисайтовых решений).
[*][b]Исключения по URL[/b]: Настройка страниц, на которых модуль не будет работать, с использованием регулярных выражений.
[*][b]Исключения по GET-параметрам[/b]: Отключение модуля на страницах с определёнными GET-параметрами.
[*][b]Автоматический поиск ключей[/b]: При наличии модулей [/b][code]awz.ydelivery[/code][b], [/b][code]awz.belpost[/code][b], [/b][code]awz.europost[/code][b] или [/b][code]fileman[/code][b], модуль пытается автоматически подставить API-ключи из их настроек.
[*][b]Поддержка enterprise-версии[/b]: При наличии API-ключа для enterprise-версии, модуль автоматически переключается на [/b][code]enterprise.api-maps.yandex.ru[/code][b].
[/list]

[size=24pt][b]Принцип работы[/b][/size]

[b]Модуль подключается к событию [/b][code]OnEndBufferContent[/code][b] ядра Bitrix. На этапе завершения формирования HTML-страницы он:[/b]

[olist]
[*][b]Проверяет, что запрос не из админки, не POST-запрос и не AJAX-запрос.[/b]
[*][b]Получает настройки для текущего сайта (в мультисайтовых проектах).[/b]
[*][b]Проверяет, не отключён ли модуль для текущего GET-параметра или URL (через регулярные выражения).[/b]
[*][b]Ищет в HTML-коде все теги [/b][code]<script>[/code][b] с подключением [/b][code]api-maps.yandex.ru[/code][b].[./b]
[*][b]Заменяет [/b][b]первое[/b][b] найденное подключение на указанный в настройках URL (с добавлением [/b][code]#awzfixymap[/code][b] для последующей очистки).[/b]
[*][b]Удаляет все остальные подключения к Яндекс Картам.[/b]
[*][b]Удаляет метку [/b][code]#awzfixymap[/code][b] из итогового HTML.[/b]
[/olist]

[size=24pt][b]Интеграция с Bitrix CMS[/b][/size]

[list]
[*][b]Установка[/b]: Модуль регистрируется в системе и подключает обработчик события [/b][code]OnEndBufferContent[/code][b].
[*][b]Настройки[/b]: Доступны через раздел [/b][quote]"Настройки модулей" → "Настройки модуля AWZ: Решение конфликтов Яндекс карт"[/quote][b].
[*][b]Мультисайтовость[/b]: Настройки хранятся отдельно для каждого сайта ([/b][code]SITE_ID[/code][b]), что позволяет гибко управлять поведением модуля в мультисайтовых проектах.
[/list]

[size=24pt][b]Настройки и конфигурация[/b][/size]

[size=22pt][b]Основные настройки[/b][/size]

[olist]
[*,][b]Включить модуль[/b] ([b]ACTIVE[/b])
   [b]- Флажок для включения/отключения модуля на текущем сайте.[/b]
   [b]- Значение по умолчанию: [/b][code]N[/code][b] (выключено).[/b]
[*,][b]URL путь к библиотеке ymaps[/b] ([b]URL[/b])
   [b]- Полный URL для подключения библиотеки [/b][code]ymaps[/code][b].[/b]
   [b]- Значение по умолчанию: автоматически формируется на основе ключей из других модулей.[/b]
[*,][b]Отключить модуль на страницах с get параметрами[/b] ([b]DSBL_GET[/b])
   [b]- Список GET-параметров (через запятую), при наличии которых модуль не будет работать.[/b]
   [b]- Пример: [/b][code]preview,edit[/code][b] — модуль отключится на страницах [/b][code]/catalog/?preview=1[/code][b] или [/b][code]/product/?edit=true[/code][b].[/b]
[*,][b]Отключить модуль на страницах по регулярному выражению[/b] ([b]DSBL_REJ[/b])
   [b]- Список регулярных выражений (каждое с новой строки), при совпадении с текущим URL модуль не будет работать.[/b]
   [b]- Примеры:[/b]
     [b]- [/b][code]/catalog/[/code][b] — точный путь (опубликуется на [/b][code]/catalog/index.php[/code][b]).[/b]
     [b]- [/b][code]#\/catalog\/*#i[/code][b] — регулярное выражение (не опубликуется на [/b][code]*\/catalog/*[/code][b]).[/b]
   [b]- данные правила приоритетнее правил включения[/b]
[*,][b]Включить модуль на страницах по регулярному выражению[/b] ([b]ENBL_REJ[/b])
   [b]- Список регулярных выражений (каждое с новой строки).[/b]
   [b]- Если задано хотя бы одно выражение в [/b][code]ENBL_REJ[/code][b], модуль сработает только на страницах, совпадающих с этими выражениями.[/b]
[/olist]
